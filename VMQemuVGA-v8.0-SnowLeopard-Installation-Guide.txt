VMQemuVGA v8.0 Snow Leopard Compatibility Release
Installation Guide for Unsigned Kext
======================================================

Package: VMQemuVGA-v8.0-SnowLeopard-Unsigned-20250825.tar.gz
Date: August 25, 2025
Compatibility: macOS 10.6.8 (Snow Leopard) and later
Status: ✅ TESTED AND VERIFIED on Snow Leopard 10.6.8

IMPORTANT: This is the unsigned version for testing and development.

📋 INSTALLATION INSTRUCTIONS

1. Extract the Archive:
   tar -xzf VMQemuVGA-v8.0-SnowLeopard-Unsigned-20250825.tar.gz

2. Install the Kernel Extension:
   sudo cp -R VMQemuVGA.kext /System/Library/Extensions/
   sudo chown -R root:wheel /System/Library/Extensions/VMQemuVGA.kext
   sudo chmod -R 755 /System/Library/Extensions/VMQemuVGA.kext

3. Update Kernel Extension Caches:
   sudo kextcache -system-caches
   sudo kextcache -system-prelinked-kernel

4. Load the Extension (optional - will load on reboot):
   sudo kextload /System/Library/Extensions/VMQemuVGA.kext

5. Reboot for Full Activation:
   sudo reboot

📊 VERIFICATION COMMANDS

Check if loaded:
   kextstat | grep -i vmqemu

View debug messages:
   sudo dmesg | grep -i vmqemu

Expected output after successful loading:
   VMQemuVGAAccelerator: Started successfully
   VMQemuVGA: 3D acceleration enabled via VirtIO GPU

⚠️  REQUIREMENTS

1. System Integrity Protection (SIP) must be disabled:
   - Boot into Recovery Mode (Cmd+R)
   - Open Terminal
   - Run: csrutil disable
   - Reboot

2. For Snow Leopard 10.6.8:
   - No additional requirements
   - Kernel extension loading restrictions are minimal

🔧 TROUBLESHOOTING

If kext fails to load:
1. Check system logs: sudo dmesg | tail -20
2. Verify permissions: ls -la /System/Library/Extensions/VMQemuVGA.kext
3. Rebuild caches: sudo kextcache -system-caches

If you see symbol errors:
- This version includes Snow Leopard compatibility fixes
- Should not occur with this release
